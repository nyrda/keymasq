# Examples

Small task-focused guides for common Keymasq workflows.

| Goal | Use this when |
|---|---|
| [Custom modifier combos](examples/custom-modifier-combos.md) | A spare key, mouse button, or gamepad button should act like a modifier for combo shortcuts. |
| [Momentary WASD navigation layer](examples/momentary-wasd-navigation-layer.md) | Holding one key should temporarily turn WASD into arrows and Q/E into Home/End. |
| [Mouse UI automation](examples/mouse-ui-automation.md) | A key or combo should replay pointer movement, clicks, and waits in an app with no good shortcut path. |
| [Text snippet macro](examples/text-snippet-macro.md) | A key or combo should type reusable text, including localized text recorded from your own keyboard layout. |
| [Universal copy and paste](examples/universal-copy-paste.md) | One key or combo should copy and paste everywhere, with terminal or app-specific shortcut overrides. |
| [Volume rocker key](examples/volume-rocker-superkey.md) | One key should turn volume down or up with rapidfire media keys or audio command macros. |
